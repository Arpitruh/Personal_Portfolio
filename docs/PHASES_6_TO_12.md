# Portfolio World — Phases 6–12

| Phase | Experience | Implementation boundary |
|---|---|---|
| 6 | Interactive Developer Room | CSS-drawn keyboard-accessible hotspots, routes to real pages; no WebGL or paid assets |
| 7 | Recruiter Mode + Resume | Accessible print-friendly professional profile; print/save PDF in browser; **no fabricated downloadable resume PDF** |
| 8 | Richer Case Studies | Source-backed feature lists, architecture *overview* clearly labelled conceptual, links and constraints |
| 9 | Performance + Accessibility | Static data, reduced motion, semantic controls, print CSS, mobile tests, no remote APIs |
| 10 | Skills Universe | Select skill family/skill to reveal actual linked projects and documentation-aware empty states |
| 11 | Achievements + Quests | Local-only visited-page badges; no analytics, tracking server or account |
| 12 | Portfolio Assistant | Deterministic, client-side search over published portfolio content; **not** a generative AI or external provider |
